Stages

#StageWhatCode
0MoGe (parallel) Kick off monocular geometry on the original image first; collect the result at the last step (runs in parallel). Saved to moge/. moge_start(), moge_fetch()
1RAM++ auto-tag Tag the image; filter structural/scene tags; format as DINO prompt. ram_autotag()
2GroundingDINO + NMS Open-vocab detect using RAM tags as prompt; class-agnostic NMS drops dup boxes. detect_objects()
3BiRefNet matte Foreground inside each DINO box (+ full-image fallback) = object mask; rug mask = BiRefNet in the DINO boxes labelled rug/carpet/mat (RUG_LABELS). birefnet_objects(), rug_boxes_from_labels(), birefnet_rug()
4Imagen empty room Inpaint-remove objects ∪ rug → bare room, pixel-aligned to original. imagen_empty_room()
5image2scene API Re-run auto_detect on the empty room → amodal wall/floor masks. api_autodetect(), _decode_masks()
6Subtract & save visible = surface − objects (floor also − rug); write masks + overlay. run_pipeline()

Notes

  • Each run bills 1 Imagen call + 1 image2scene API job per sample.
  • SAM dropped — wall/floor now come from the image2scene API re-run, not local SAM point prompts.
  • No original auto_detect.json input needed — only downsample.jpg per sample. Rug comes from DINO labels; wall/floor from the API re-run (which writes its own from-api/auto_detect.json).
  • run.py mirrors this exactly (same functions); main_short.ipynb adds inline visualizations.
  • Tune OBJECT_PROMPT fallback, RAM_EXCLUDE, RUG_LABELS, DINO_BOX_THRESH, NMS_IOU against the dinoviz1 output.
